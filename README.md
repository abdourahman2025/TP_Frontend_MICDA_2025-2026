# Page d'accueil UN-CHK (TP Frontend MICDA 2025-2026)

## Membres
- Aby Mbadj

## Description
Reproduction de l'interface de la page d'accueil du site de l'Université Numérique Cheikh Hamidou Kane (UN-CHK) :
en-tête avec logo, menu de navigation, bouton MENU et recherche, carrousel de trois diapositives
(avec miniatures, flèches et défilement automatique), section « Nos formations » et pied de page.
La page est responsive : le menu se replie derrière le bouton MENU sur petit écran.

Projet pédagogique : le logo et les visuels sont des substituts ou des images à titre d'illustration.

## Technologies utilisées
- HTML5
- CSS3 (Flexbox, Grid, media queries)
- JavaScript (carrousel et menu mobile)

## Exécution
1. Télécharger ou cloner le projet.
2. Ouvrir le fichier `unchk.html` dans un navigateur (double-clic).
   Aucune installation n'est nécessaire.
   (Option : lancer avec l'extension Live Server de VS Code.)
