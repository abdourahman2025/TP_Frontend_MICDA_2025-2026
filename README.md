# TP1 - Page d'accueil UNCHK

TP Frontend - Librairies et frameworks frontend (MICDA 2025-2026)

## Membres

- Seydina Aliou DIAKITE / N03651820211

## Description

Reproduction de la page d'accueil du site de l'Université numérique Cheikh Hamidou Kane (http://www.unchk.sn) en HTML et CSS.

La page contient :
- un en-tête avec le logo de l'unchk, le menu de navigation, le bouton MENU et de la recherche ;
- une bannière « Appel à candidatures » avec les miniatures, les flèches et la photo.

Les dates et le lien de candidature de la bannière sont des exemples.

## Technologies utilisées

- HTML5
- CSS3
