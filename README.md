## 3. Description du projet
UNCHK HOMEPAGE est un projet de développement Frontend
consistant à concevoir une page d'accueil web pour
présenter l'Université Numérique Cheikh Hamidou Kane.

Le site présente notamment :
- Les actualités de l'université ;
- Les informations sur les étudiants ;
- La vie estudiantine ;
- Les activités sportives ;
- Les informations générales de l'université.

## 4. Technologies utilisées
- HTML5
- CSS3
- Git
- GitHub
- XAMPP

## 5. Instructions pour exécuter le projet

1. Installer XAMPP.
2. Copier le dossier du projet dans le répertoire htdocs.
3. Démarrer Apache depuis XAMPP.
4. Ouvrir un navigateur web.
5. Accéder à cette adresse :

http://localhost/unchk-homepage/TP_Frontend_MICDA_2025-2026/
