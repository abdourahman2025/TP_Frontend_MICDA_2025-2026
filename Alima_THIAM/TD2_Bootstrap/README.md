# TD2 – Librairie Framework Frontend (Bootstrap)

Site vitrine « Découverte du Sénégal » réalisé avec **Bootstrap 5**.

- **Membre :** Alima THIAM (travail individuel)
- **Formation :** Master MICDA – UN-CHK
- **Cours :** Librairie et Framework Front end – Dr Abdourahmane BALDÉ

## Structure du projet

```
TD2-Bootstrap/
├── index.html        → la page (structure HTML + classes Bootstrap)
├── css/
│   └── style.css     → styles personnalisés (couleurs, bandeau, cartes…)
├── js/
│   └── script.js     → menu actif au défilement, fermeture du menu mobile
├── images/           → photos du site
│   ├── monument.jpg
│   ├── dakar.jpg
│   ├── lac-rose.jpg
│   └── casamance.jpg
└── README.md
```

## Technologies

- HTML5 / CSS3 / JavaScript
- [Bootstrap 5.3](https://getbootstrap.com/) (CDN) : grille, navbar, cartes, boutons, utilitaires
- [Bootstrap Icons](https://icons.getbootstrap.com/) (CDN)
- Police Google Fonts « Poppins »

## Lancer le projet

- Ouvrir `index.html` dans un navigateur,
- ou, dans VS Code, clic droit sur `index.html` → **Open with Live Server**.

Une connexion Internet est nécessaire pour charger Bootstrap, les icônes et la police.

## Sections de la page

1. Barre de navigation (menu burger sur mobile)
2. Bandeau d'accueil avec le Monument de la Renaissance africaine
3. Lieux incontournables : Dakar, Lac Rose, Casamance (cartes)
4. Points forts : paysages, culture, tourisme durable
5. Pied de page avec réseaux sociaux
