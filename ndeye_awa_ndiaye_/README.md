# Découverte du Sénégal

TP Frontend — Master MICDA 2025-2026

## Description

Page d'accueil responsive de présentation touristique du Sénégal, réalisée avec **HTML**, **CSS** et **Bootstrap 5**.

La page présente trois destinations (Dakar, le Lac Rose et la Casamance) ainsi que les atouts du pays : paysages uniques, culture riche et tourisme durable.

## Contenu de la page

- Barre de navigation responsive (menu burger sur mobile)
- Section d'accueil (hero) avec image de fond et bouton « Explorer maintenant »
- Trois cartes de destinations : Dakar, Le Lac Rose, La Casamance
- Section des atouts du Sénégal avec icônes
- Pied de page avec liens vers les réseaux sociaux

## Technologies utilisées

- HTML5
- CSS3
- Bootstrap 5.3 (grille, navbar, cartes, boutons, utilitaires)
- Bootstrap Icons

## Lancer le projet

1. Télécharger ou cloner le dépôt.
2. Ouvrir le fichier `index.html` dans un navigateur.

Une connexion internet est nécessaire pour charger Bootstrap et Bootstrap Icons depuis leur CDN.
